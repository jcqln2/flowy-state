## Important Note on On Chain Glow

The On Chain Glow website features an animated 3D/WebGL design where individual balloon letters float independently. This artistic design inherently displays the title with "GLOW" split across different positions:
- "ON" (top left) and "OW" (top right)
- "CHAIN GL" (middle)

After extensive testing with various:
- Viewport sizes (mobile, tablet, desktop, ultrawide)
- Timing captures (1s to 15s intervals)
- Animation frame monitoring

The balloon layout remains consistent with this split design. This appears to be an intentional artistic choice by the website designer rather than a timing issue. The captured screenshot provides a clean, well-composed frame with all letters clearly visible and the full branding intact.
